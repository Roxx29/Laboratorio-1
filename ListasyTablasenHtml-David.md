Listas No Ordenadas (<ul>)
Crea una lista con viñetas donde el orden de los elementos no es importante. Se usa para agrupar items relacionados sin una secuencia específica.
<ul>
  <li>Manzana</li>
  <li>Naranja</li>
  <li>Pera</li>
</ul>
Listas Ordenadas (<ol>)
Genera una lista numerada automáticamente. Ideal para mostrar pasos, instrucciones o cualquier contenido donde el orden sea relevante.
<ol>
  <li>Precalentar horno</li>
  <li>Mezclar ingredientes</li>
  <li>Hornear 30 min</li>
</ol>
Tablas (<table>)
Organiza información en filas y columnas. Perfecta para mostrar datos estructurados, comparaciones o información tabular de manera ordenada.
<table>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>María</td>
    <td>25</td>
  </tr>
</table>
