Comandos básicos en HTML

HTML (HyperText Markup Language) es el lenguaje de marcado que se utiliza para estructurar páginas web. Está compuesto principalmente por etiquetas, que indican al navegador cómo mostrar el contenido.

¿Qué son las etiquetas en HTML?

Las etiquetas son comandos escritos entre signos de menor < y mayor > que delimitan el inicio y el fin de un elemento. Generalmente, la mayoría de las etiquetas vienen en pares: una de apertura y otra de cierre.

Ejemplo general:
<tag>Contenido</tag>

<tag> → etiqueta de apertura

</tag> → etiqueta de cierre

Contenido → el texto o elementos que estarán dentro de la etiqueta

Ejemplos de etiquetas básicas

<html>
Es la etiqueta raíz que envuelve todo el contenido de la página web.

<head>
Contiene información sobre la página, como el título, enlaces a hojas de estilo, metadatos, etc.

<body>
Contiene todo el contenido visible de la página, como textos, imágenes, enlaces y tablas.
